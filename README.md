# Menu previews

Sanitized static menu demonstrations. No private registry, messages, attachments or operational records belong in this repository.

The hourly expiry workflow stages only route removals, the two campaign indexes,
the lifecycle manifest and sanitized cleanup receipts. Its staging helper handles
an already absent `r/` directory and retains tracked deletions. The same safeguard
test suite covers receipt commits, deletion staging, unrelated-file exclusion and
clean reruns: `python3 -m unittest discover -s tests`.

The restaurant path serves the current preview. Menu/version paths are frozen once published. Menu content version 3 was first delivered by website build 265.2. Frozen v2 remains unchanged. The La Paella v3 sample selects the first source page of each of the first two categories (four salads and four starters), with all six source languages.

Build 267.3 updates the 40 active September 22 and September 24 prospect samples, retains the continuous language-and-menu experience introduced in 265.2, and keeps menu content at version 3. Every sampled food section has at least one suitable image and retains any higher count of usable original menu photos from its sampled source pages. When no suitable original is available, a clearly labelled AI illustration fills the section. Each sample ends with its QR-pyramid animation, reduced-motion still image, and four localized email CTAs; each opens a prefilled email to `info@web-by-elie.com` and does not send it. Frozen menu/version routes remain unchanged.
